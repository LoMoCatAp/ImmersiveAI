# Feature Specification: ImmersiveAI 底部沉浸布局、“我的”入口与核心流程修复

**Created**: 2026-07-25  
**Status**: Draft — Phase 1 requirement review  
**Input**: 用户反馈底部白框、内容和导航被挤压、材质设置入口位置错误，并确认参考 ClashBox 的全屏布局和设置入口模式。

## Overview

本轮修复 ImmersiveAI 当前未解决的底部布局问题：页面底部出现大块白色区域，页面内容和导航栏被整体挤压到上方。应用必须使用完整窗口布局，底部系统安全区与页面/HDS 背景保持一致，导航栏位于安全区内且不遮挡内容。

沉浸光感材质设置不再放在供应商页面，而是放入新增的底部“我的”导航页签；用户点击“我的”中的材质设置入口后，在独立设置页面或设置区域中修改四档官方材质。继续修复上一轮未解决的 Provider、Chat、History 核心流程，并参考 `C:\Files\Codes\HarmonyApps\fork\ClashBox-master` 的全屏根容器、内容与底部 Tabs 分离、More/Appearance 设置列表入口模式，不复制其业务实现。

## User Scenarios & Testing

### User Story 1 - 全屏底部布局与安全区导航 (Priority: P1)

用户启动应用后，页面内容从顶部连续铺满到窗口底部；底部不再出现独立白色大块，内容和底部导航不会被根容器额外间距挤压。导航栏贴近系统底部安全区，但不进入系统导航指示器区域、不贴物理边缘、不被裁剪。

**Why this priority**: 当前页面整体布局错误，所有内容和导航被挤压，直接影响所有功能使用。

**Independent Test**: 在聊天、历史、供应商和“我的”四个页签分别查看页面顶部、内容底部和导航位置，切换深浅色或系统安全区后确认底部背景连续且核心内容可见可点。

**Acceptance Scenarios**:

1. **Given** 应用启动完成，**When** 用户查看页面底部，**Then** 不出现与页面背景不一致的大块白色区域。
2. **Given** 页面有可滚动内容，**When** 用户滚动到底部，**Then** 最后一项、输入区和操作按钮不被导航栏遮挡，导航栏不把全部内容挤到上方。
3. **Given** 系统存在底部导航指示器安全区，**When** 用户查看底部 HDS 导航，**Then** 导航位于安全区可用区域内，不进入指示器区域、不贴物理边缘、不被裁剪。
4. **Given** 用户切换聊天、历史、供应商和“我的”，**When** 页面内容变化，**Then** 根窗口高度和底部布局保持稳定，不出现白框或跳动挤压。

### User Story 2 - “我的”页签中的沉浸光感设置 (Priority: P1)

用户可以在底部导航栏点击“我的”，在“我的”页面看到“沉浸光感材质”设置入口；点击入口后进入设置区域，选择四档官方材质并立即看到当前选择状态。设置结果影响顶部和底部 HDS 导航，并在重新启动后恢复。

**Why this priority**: 用户明确要求材质设置入口位于导航栏“我的”中，而不是供应商页面；设置入口位置必须符合用户心智模型。

**Independent Test**: 点击“我的”→点击“沉浸光感材质”→依次选择四档→返回主页面观察状态→重启应用确认选择恢复。

**Acceptance Scenarios**:

1. **Given** 底部导航显示“我的”，**When** 用户点击“我的”，**Then** 显示“我的”页面且“我的”页签处于选中态。
2. **Given** 用户位于“我的”页面，**When** 用户点击“沉浸光感材质”入口，**Then** 显示四档设置区域，而不是跳转到供应商编辑页面。
3. **Given** 四档设置区域已显示，**When** 用户选择任一档位，**Then** 选择状态立即更新，并真实显示可用、降级或不可用原因。
4. **Given** 用户选择了材质档位，**When** 用户返回聊天、历史或供应商，**Then** 顶部和底部 HDS 材质状态同步更新，不重置其他业务状态。
5. **Given** 用户选择档位后关闭并重新启动应用，**When** 用户打开“我的”设置，**Then** 上次选择被恢复；默认未选择时为 GENTLE，并显示“均衡（默认）”。

四档固定定义：

- `EXQUISITE`：强；完整的沉浸光感效果，包含所有视觉特性，适合高性能设备。
- `GENTLE`：均衡（默认）；适度的沉浸光感效果，在视觉效果与性能之间取得平衡。
- `SMOOTH`：弱；轻量级沉浸光感效果，仅保留核心视觉特性，适合低性能设备。
- `ADAPTIVE`：系统自适应；由系统根据设备性能自动选择合适的档位，推荐大多数场景使用。

### User Story 3 - 供应商核心流程可用 (Priority: P1)

用户可以完成供应商新增、编辑、取消、保存、连接测试、重试、启停、删除、导入确认/取消和清空。密钥输入聚焦、输入和取消时页面保持可见，不黑屏、不崩溃，密钥不出现在页面反馈或日志中。

**Why this priority**: 上一轮密钥输入黑屏和供应商按钮流程仍未解决，阻断聊天配置。

**Independent Test**: 在供应商页完成新增/编辑、聚焦密钥、输入后取消，再进行保存、测试、目标供应商重试、启停、删除和导入操作，确认每步有中文反馈。

**Acceptance Scenarios**:

1. **Given** 用户打开新增或编辑表单，**When** 聚焦、输入或取消密钥，**Then** 页面保持可见，键盘不导致白屏/黑屏，密钥保持遮罩或受保护状态。
2. **Given** 用户正在编辑供应商，**When** 点击“取消编辑”，**Then** 表单清理并返回供应商列表，不依赖系统返回手势。
3. **Given** 用户点击保存、测试、启停、删除、导入确认、导入取消或清空，**Then** 显示明确的中文处理中、成功、失败、确认或取消反馈。
4. **Given** 某个供应商连接测试失败，**When** 用户点击重试，**Then** 重试明确针对该供应商，不调用无目标的空操作。

### User Story 4 - Chat 与 History 跨页核心流程可用 (Priority: P1)

用户可以从聊天空状态进入供应商设置并明确返回聊天；返回后“聊天”页签选中态正确。有配置时可以选择供应商/模型、发送、停止、重试和复制。用户可以新建、打开、重命名保存/取消和删除历史会话，并获得即时中文反馈和正确持久化。

**Why this priority**: 上一轮聊天返回选中态、历史新建和重命名仍未完成闭环。

**Independent Test**: 分别执行 Chat 的配置引导/返回和按钮矩阵，以及 History 的新建/打开/重命名/取消/删除矩阵，确认目标状态正确。

**Acceptance Scenarios**:

1. **Given** 没有启用供应商，**When** 用户点击聊天配置引导，**Then** 进入供应商设置并显示中文反馈。
2. **Given** 用户在供应商设置，**When** 点击明确“返回聊天”，**Then** 返回聊天页面且底部“聊天”页签同步选中。
3. **Given** 存在可用配置，**When** 用户发送、停止、重试或复制，**Then** 每项显示中文状态或明确不可用原因，重试不重复用户消息。
4. **Given** 历史页打开，**When** 用户点击“新建会话”，**Then** 立即显示处理中或成功反馈，并创建/切换到新会话。
5. **Given** 存在历史会话，**When** 用户打开、重命名并保存或取消，**Then** 目标会话正确更新或恢复，且显示中文反馈。
6. **Given** 存在多个会话，**When** 用户删除一个目标会话并确认，**Then** 只删除目标会话及其消息，其他会话保留。

### Edge Cases

- 根容器安全区配置导致底部重复占用、白色背景或内容高度被压缩。
- HDS 自带底部安全区避让与应用自定义 bottom padding 同时生效，产生双重空白。
- “我的”页面进入设置后返回，底部选中态或材质选择丢失。
- 四档材质能力不可用、设备降级或 HDS 未呈现真实效果时，页面不得宣称成功。
- 键盘出现时供应商表单被遮挡、黑屏或页面尺寸异常。
- 中文长文案在窄屏、深色模式和底部安全区中溢出或遮挡点击区。
- HDS 组件和普通 fallback 的布局尺寸不一致，切换时出现跳动或再次出现白框。

## Requirements

### Functional Requirements

- **FR-001**: 所有用户可见文案 MUST 使用简体中文。
- **FR-002**: 页面根布局 MUST 占满应用窗口，不得通过根级底部 padding 将内容和导航整体挤压到上方。
- **FR-003**: 底部系统安全区的背景 MUST 与当前页面/HDS 材质视觉连续，不得出现独立的大块白色背景。
- **FR-004**: 底部导航 MUST 位于系统底部安全区可用区域内，不进入系统导航指示器区域、不贴物理边缘、不被裁剪。
- **FR-005**: Chat、History、Provider Settings 和“我的”内容 MUST 使用独立的内容底部空间，避免被底部导航遮挡；该空间不得改变导航栏本身的位置。
- **FR-006**: 底部导航 MUST 新增“我的”页签，并保持聊天、历史、供应商入口可访问。
- **FR-007**: “我的”页面 MUST 提供“沉浸光感材质”可点击入口；材质设置不得继续作为供应商页面的入口。
- **FR-008**: 材质设置 MUST 提供 EXQUISITE、GENTLE、SMOOTH、ADAPTIVE 四个官方档位及固定中文定义。
- **FR-009**: 材质选择 MUST 使用当前 SDK 可验证的系统 HDS 材质能力，查询真实设备能力，并显示真实的可用、降级或不可用原因。
- **FR-010**: 材质选择 MUST 持久化，立即同步到 HDS 顶部导航和底部导航，并在应用重启后恢复。
- **FR-011**: HDS 动态光感 MUST 由系统材质、交互和滚动能力提供，不得使用渐变、普通透明、阴影、普通模糊或自制动画冒充。
- **FR-012**: Provider、Chat、History 和“我的”所有核心入口 MUST 具备有效点击区域、回调、状态刷新和中文反馈。
- **FR-013**: 密钥输入、取消和保存 MUST 不导致黑屏、白屏或崩溃；Key MUST 保持遮罩或受保护，不得出现在反馈和日志中。
- **FR-014**: Provider 编辑 MUST 提供显式“取消编辑”，连接测试重试 MUST 绑定明确供应商。
- **FR-015**: Chat 配置引导返回 MUST 同步聊天内容和底部“聊天”选中态。
- **FR-016**: History 新建 MUST 立即反馈并创建/切换会话；重命名 MUST 支持保存和取消；删除 MUST 只影响目标会话。
- **FR-017**: 参考 ClashBox 时 MUST 只采用其全屏根布局、内容与底部 Tabs 分离、More/Appearance 设置入口模式；不得复制其业务代码或改变 ImmersiveAI 既有业务边界。
- **FR-018**: 本轮 MUST 在目标 HUAWEI Mate 70 Pro 上验证底部布局、“我的”入口、材质设置和核心流程；若设备不可用，必须明确记录实际验证设备和未验证项。

### Key Entities

- **ShellTab**：聊天、历史、供应商、我的四个底部导航项及选中状态。
- **MySettingsEntry**：我的页面中的沉浸光感材质设置入口、当前摘要和可用状态。
- **MaterialPreference**：四档材质等级、固定中文标签、默认值、能力状态和持久化状态。
- **SafeAreaLayout**：窗口铺满状态、系统底部安全区、导航视觉位置和内容底部空间。
- **OperationFeedback**：加载、成功、失败、取消、确认、重试和中文提示。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 在目标设备上，页面底部不再出现与页面背景不一致的大块白色区域，四个页签的内容和导航均保持连续布局。
- **SC-002**: 在聊天、历史、供应商和我的页面中，底部核心内容均可滚动到并完整显示，导航栏不遮挡最后一项或输入区。
- **SC-003**: 用户从底部导航进入“我的”并打开材质设置的操作路径清晰，最多两次点击进入设置区域。
- **SC-004**: 四档材质的选择状态在 1 秒内更新，并在重启后恢复；未选择时 GENTLE 显示“均衡（默认）”。
- **SC-005**: 供应商、聊天和历史核心操作的中文反馈在 1 秒内出现，失败时不静默。
- **SC-006**: 密钥输入聚焦、输入、取消和保存过程中页面保持可见且不崩溃，Key 不出现在页面反馈或日志中。
- **SC-007**: 目标设备验证记录明确区分 HDS 系统材质成功、真实降级和不可用状态；普通 fallback 不计为 HDS 成功。

## Assumptions

- “我的”是新增的第 4 个底部页签；既有“聊天 / 历史 / 供应商”入口继续保留。
- 底部白框的处理目标是安全区同材质：页面视觉延伸到底部安全区，安全区仍保留系统避让，不进入系统导航指示器。
- ClashBox 仅作为本地参考工程，参考其布局和设置入口组织方式，不复制代码和业务逻辑。
- 保留现有数据库 schema、协议适配、流式聊天、Asset Store Kit、用户端点来源和凭据存储边界。
- 目标设备为 HUAWEI Mate 70 Pro；若无法连接，验证报告必须标注替代设备及限制。
